# Tool interface

Generated by `tests/interface.rs` from a running server; don't edit by hand. Regenerate with `UPDATE_INTERFACE=1 cargo test --test interface`. See [versioning.md](versioning.md) for what may change between releases.

Output fields are listed as paths: `findings[].pattern_id` is a field of each item of `findings`. They are the fields seen with `detail: "full"`; brief answers have a subset, and a field with nothing to say may be left out.
